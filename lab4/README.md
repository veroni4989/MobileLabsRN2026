# Файловий менеджер. Лабораторна робота4
## Інструкція запуску

### Через Expo Snack (онлайн)
1. Відкрити https://snack.expo.dev
2. Вставити код з файлу App.js у кореневий файл проєкту
3. У package.json додати залежність: "expo-file-system": відповідна версія для обраного SDK
4. Натиснути Save та переключитись на вкладку Android або iOS
5. Протестувати функціонал у вбудованому симуляторі

### Залежності (package.json)
{
  "dependencies": {
    "expo-file-system": "~17.0.1"
  }
}

## Опис реалізованого функціоналу

### Архітектура застосунку
Реалізовано у вигляді єдиного компонента App.js з двома режимами відображення:
- Browser — перегляд файлової системи
- Editor — редагування текстового файлу

### 1. Навігація по файловій системі
- Відображення поточного шляху у вигляді breadcrumb (Documents/subfolder/...)
- Вивід вмісту поточної директорії через FlatList: папки і файли
- Перехід у вкладені папки (натискання на папку)
- Повернення назад через кнопку "Вгору" (стек попередніх шляхів)
- Сортування: спочатку папки, потім файли (алфавітний порядок)

### 2. Створення
- Створення нової папки через модальне вікно з TextInput (FileSystem.makeDirectoryAsync)
- Створення нового .txt файлу з назвою та початковим вмістом (FileSystem.writeAsStringAsync)
- Якщо назва файлу не містить .txt — розширення додається автоматично

### 3. Зчитування
- Відкриття .txt файлів у вбудованому текстовому редакторі (FileSystem.readAsStringAsync)
- При спробі відкрити файл іншого формату — відображається попередження

### 4. Редагування
- Повнофункціональний TextInput для редагування вмісту файлу
- Індикатор незбережених змін (жовтий банер "Є незбережені зміни")
- Збереження через кнопку "Зберегти" (FileSystem.writeAsStringAsync)
- При виході з несохраненими змінами — Alert з підтвердженням

### 5. Видалення
- Кнопка видалення (X) на кожному елементі списку
- Alert.alert з підтвердженням перед видаленням
- Видалення через FileSystem.deleteAsync з опцією idempotent: true

### 6. Детальна інформація про файл
- Доступна через кнопку "i" або довгий натиск на елемент
- Модальне вікно виводить:
  - Назва файлу або папки
  - Тип (розширення файлу або "Директорія")
  - Розмір (для файлів, у зручному форматі: B / KB / MB / GB)
  - Дата останньої модифікації (локалізована: дд.мм.рррр гг:хх)

### 7. Статистика пам'яті пристрою
- Відображається у верхній частині екрану (iOS/Android)
- Три картки з показниками:
  - Всього: загальний обсяг пам'яті пристрою
  - Вільно: доступний вільний простір
  - Зайнято: використаний простір (Total - Free)
- Прогрес-бар використання пам'яті з відсотком

### Використані API expo-file-system

| Метод | Призначення |
|-------|-------------|
| FileSystem.documentDirectory | Кореневий шлях застосунку |
| FileSystem.readDirectoryAsync(path) | Список вмісту директорії |
| FileSystem.getInfoAsync(path) | Інформація про файл/папку |
| FileSystem.makeDirectoryAsync(path) | Створення директорії |
| FileSystem.writeAsStringAsync(path, content) | Запис/створення файлу |
| FileSystem.readAsStringAsync(path) | Зчитування вмісту файлу |
| FileSystem.deleteAsync(path) | Видалення файлу або папки |
| FileSystem.getTotalDiskCapacityAsync() | Загальний обсяг пам'яті |
| FileSystem.getFreeDiskStorageAsync() | Вільний обсяг пам'яті |
