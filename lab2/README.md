## Опис реалізованого функціоналу

- **Drawer Navigator** — бокове меню з кастомним компонентом
- **Stack Navigator** — вкладений у Drawer для переходу між екранами новин
- Передача параметрів між екранами (title, description, image, id)
- Динамічний заголовок екрану деталей на основі параметрів

### MainScreen — FlatList (список новин)
- **Pull-to-Refresh** — оновлення списку жестом потягування вниз
- **Infinite Scroll** — автоматичне підвантаження нових новин при прокрутці
- **ListHeaderComponent** — кастомна шапка з кнопкою відкриття меню
- **ListFooterComponent** — індикатор завантаження або ПІБ студента
- **ItemSeparatorComponent** — роздільник між елементами
- Параметри оптимізації: `initialNumToRender=10`, `maxToRenderPerBatch=5`, `windowSize=10`

### DetailsScreen — деталі новини
- Отримання параметрів через `route.params`
- Динамічний заголовок у заголовку Stack Navigator

### ContactsScreen — SectionList (список контактів)
- Групування контактів за першою літерою
- `sections`, `renderItem`, `renderSectionHeader`, `keyExtractor`
- `ItemSeparatorComponent` між контактами
- `stickySectionHeadersEnabled` — липкі заголовки секцій

### CustomDrawer — кастомне бокове меню
- Аватар (зображення)
- ПІБ студента
- Група
- Пункти меню: Новини, Контакти
- Підсвічування активного пункту

## Висновки (контрольні запитання)

**1. Чим відрізняється FlatList від ScrollView?**
FlatList використовує механізм віртуалізації відображає лише видимі елементи, невидимі видаляє з пам'яті. ScrollView рендерить усі елементи одразу, що призводить до значного навантаження при великих списках.

**2. Що таке віртуалізація списків?**
Техніка оптимізації, при якій рендеряться лише елементи у видимій області екрану. Елементи поза межами видимості видаляються та перестворюються при прокрутці, що значно зменшує споживання пам'яті.

**3. Як здійснюється передача параметрів між екранами?**
Через `navigation.navigate('ScreenName', { param1: value1 })`. На екрані-одержувачі параметри доступні через `route.params`. Заголовок екрану можна динамічно налаштувати через `options={({ route }) => ({ title: route.params?.title })}`.

**4. Що таке вкладена навігація?**
Архітектура, при якій один навігатор містить інший. Наприклад: Drawer Navigator містить Stack Navigator, який управляє переходами між MainScreen та DetailsScreen Це дозволяє комбінувати різні типи навігації в одному застосунку.

**5. У яких випадках застосовується SectionList?**
SectionList використовується для відображення згрупованих даних — наприклад, список контактів по алфавіту, товари по категоріях, повідомлення по датах. Кожна секція має свій заголовок та набір елементів.
