## Способи запуску мобільного додатка

### 1. Expo Go — реальний фізичний пристрій
**Призначення:** Тестування на справжньому смартфоні (Android).  
**Як запустити:** Встановити додаток **Expo Go** зі магазину → запустити `npx expo start --tunnel` → відсканувати QR-код.  
**Особливості:** Найближче до реального досвіду користувача. Відображає справжню швидкість, анімації та поведінку на конкретному пристрої.  
**Відмінності:** Деякі нативні API (камера, push-сповіщення) можуть потребувати додаткового налаштування. Вимагає стабільного Wi-Fi.

---

### 2. Android Emulator (AVD)
**Призначення:** Тестування Android-версії без фізичного пристрою на ПК.  
**Як запустити:** Відкрити Android Studio AVD Manager.  
**Особливості:** Можна тестувати різні розміри та версії Android без реального пристрою.  
**Відмінності:** Повільніший запуск порівняно з реальним пристроєм. Не передає всі сенсори (GPS, акселерометр). Потребує потужного ПК.

---

### 3. ІOS Simulator (тільки macOS)
**Призначення:** Тестування iOS-версії додатку.  
**Як запустити:** Встановити Xcode після `npx expo start` натиснути клавішу `i`.  
**Особливості:** Доступний лише на комп'ютерах Apple (macOS). Показує, як додаток виглядає на iPhone.  
**Відмінності:** Не підтримує симуляцію камери, Touch ID та деяких апаратних функцій. Не можна встановити на Windows.

---

### 4. Expo Snack (онлайн-середовище)
**Призначення:** Швидке прототипування та демонстрація без встановлення ПЗ.  
**Як запустити:** Відкрити [snack.expo.dev](https://snack.expo.dev), вставити код, натиснути **Web** або **My Device**.  
**Особливості:** Не потрібно нічого встановлювати достатньо браузера. 
**Відмінності:** Обмежені можливості файлової системи та нативних API. Може мати затримку при першому завантаженні. Ідеально для навчання та демонстрацій.
